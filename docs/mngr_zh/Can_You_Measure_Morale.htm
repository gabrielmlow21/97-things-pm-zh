提升团队的士气

David Bock Reston, Virginia, USA

软件项目经理的一个重要职责，是营造一个能促进团队士气提升的工作环境。下面是一些帮助你着手这一过程的建议：

  • 让团队对项目的方向有一定的控制权。你经常和团队交谈吗？你会定期征求他们的意见吗？有人向你提出建议或抱怨时，能感觉到你会因此积极努力地做出改变吗？
  • 保护团队不受“官僚主义”的侵扰。每个组织都有它的一套规章制度，而你的工作之一就是结合具体情况来执行它们。“结合具体情况”意味着，在适当的时候，你会为团队辩护。

当公司发出备忘录，规定禁止装饰工位时，你会去和管理层争辩，让比尔能继续展示他收藏的魔方吗？即使你输了，团队的士气也会受益。

  • 想办法改善工作环境。我认识一位工程师，他的工位挨着一扇窗户。但是，根据公司的组织结构图，他的级别配不上一间有窗户的办公室。公司的解决办法是什么？重新布置工位，把他工作区域里的那扇窗户挡住。一位好的经理不会去和“家具警察”争论，而是第一个动手挪开那些隔板，让窗户重见天日。
  • 让团队感觉自己是一个团队。有一个团队设立了“每周最佳队员奖”，每周在团队会议上易手。拉斯可能会说：“我把团队最佳队员奖颁给玛丽，因为她周四工作到很晚。我给她文档给晚了，但多亏了她的努力，我们还是在周五上午完成了这次迭代。”下一周，玛丽会表彰另一位团队成员的贡献，并把奖项传下去。
  • 尊重工作与生活的平衡。偶尔要求大家加班是可以的，但如果你要占用他们生活中的时间，就需要还一些回去。你的员工不应该害怕预约上午去看医生，或者下午去参加孩子的演出，尤其是在他们为了赶截止日期加班到很晚之后。
  • 了解因果关系如何塑造士气。如果你只是试图重现过去团队中激励你或他人的东西，你可能会遗漏关键的要素。如果你问自己“我能做些什么来改善团队的工作条件？”，并真正努力去做出这些改变，士气通常就会提高。
  • 确保你的活动是看得见的。你也是团队的一员，所以团队应该知道你在为他们做什么工作。人们很容易不信任一个总是躲在紧闭的门后的经理，而很容易追随一个公开地、看得见地为团队利益而工作的经理。

在你的组织中，会有一些提升士气的独特机会。有意识地去寻找并利用它们。如果它们奏效了，就和别人分享。
