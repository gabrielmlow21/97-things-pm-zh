先想清楚终点

Luis E. Torres, PMP San Rafael, Alajuela, Costa Rica

恭喜你！那个人人都想管的梦想软件项目，落到了你手里。公司所有的期望都压在你肩上。直觉告诉你，赶紧跑回座位开始起草项目进度表，对吧？其实，为了提高项目成功的机会，有好几件事要先做。其中一件就是：“先想清楚终点”。

首先，拿出工作说明书（SOW）、合同，或任何能告诉你客户想要什么、需要什么的文件。找出“想要”和“需要”的区别（我想要一辆 SUV，可我需要的是一辆省油的小车）。这样，你就更有条件把两者结合起来，回答这些问题：“我们要达成什么？”“对客户、对我的公司、对我自己来说，怎样才算成功？”“要取得这样的成功，需要什么？”

最后一个问题的答案，远不止“合理的利润”。你希望客户以后还来找你，希望项目团队成员愿意再和你共事，也希望自己成为别人乐于推荐的榜样。

正确的态度和带人的本事，对你作为项目经理的成功至关重要。召集项目团队成员开个启动会，一起过一遍工作说明书，对必须交付的东西形成共同的理解。

接下来，定义项目范围，也就是工作分解结构（WBS）。找出你必须满足的质量标准。排出进度。算出需要多少钱。这些要素（范围、质量、工期和成本），就是你需要监控的基本要素，也是项目计划的基石。

把项目拆成便于管理的小块之后，你要确定最终产品必须具备哪些特性，才能满足项目的质量要求。把项目的大小（范围）和必须遵守的“规矩”（质量）都弄清楚后，你就更能判断完成它要花多少时间。

要算出完成项目需要多少时间，你需要知道每项任务的工期、各项任务之间的依赖关系、具体的约束条件，以及你能调用的资源。成本放在最后，因为它通常取决于你要做的工作，以及完成这些工作所需的时间和资源。比如，你请一位顾问来做某项具体任务，安排他/她干一周的费用，和让他/她在你的项目上干上比如说 10 个月的费用，是不一样的。最后，还要考虑采购、沟通和人力资源。

先想清楚终点，你成功的机会就会大得多。
