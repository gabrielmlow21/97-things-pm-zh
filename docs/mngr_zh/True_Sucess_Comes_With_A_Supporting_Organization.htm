真正的成功来自一个支持性的组织

Cindy Berg, Phd (ABD), PMP Glendale, Arizona, USA

如果组织回避风险规划、积极发现问题和及时解决问题，原因可能出在文化上。项目团队中那些唱反调的人，常常被贴上麻烦制造者的标签。如果组织动不动就“枪毙报信人”，团队成员就会避免分享棘手的问题，并且可能倾向于隐瞒项目问题。

这种文化环境助长了推卸责任的行为，损害了整个组织、员工个人以及客户的利益。软件项目经理的职责是提供可预测的项目交付，尽可能少地出现意外事件。如果没有人及早指出陷阱，往往就会出现“意外”。这些意外很少是好事，而通常是糟糕的意外，说明由于开发人员隐瞒问题、不让其暴露，预见和规划根本无从谈起。

明智的高管会确保公司支持那些能让开发人员有效工作的态度和行为。这包括评估人力资源政策和激励计划，确保它们与那些能开发出强大产品和服务的行为相一致。

一个典型的不一致的例子是：一个组织在官方层面“宣扬”团队合作，却总是奖励个人贡献。人们很聪明，他们知道哪条路最符合自己的利益。如果高层管理者能让他们所宣称的信念，与他们为鼓励高效行为而提供的工作环境保持一致，那么个人和组织都能蓬勃发展。

如果你发现自己身处一个不提供支持或运转不良的组织中，下面是一些你可以采取的步骤：

  1. 不断地问，直到你理解项目的范围，这样你才能在范围之内工作。
  2. 找到可能的团队成员和其他干系人。只要有可能，就让他们参与头脑风暴、规划和项目执行。
  3. 让那些实际干活的人充分参与项目的更新和决策，至少在他们完成在这个项目上的活动之前都要如此。
  4. 始终做一名诚实的软件项目经理。永远不要为了避免冲突或令人不快的讨论而掩饰或简化问题。
  5. 在你的项目团队内部营造你希望整个组织都能效仿的环境。

项目经理必须对项目保持客观。他们处在一个吃力不讨好的位置上：首先要效忠于给他们发工资的组织，同时又需要与开发人员建立信任。如果项目前景黯淡，一位精明而有原则的项目经理应该建议取消项目，直到外围问题得到解决。

我们都希望在一个拥有一致战略、支持新软件项目开发的组织中工作。但遗憾的是，即使在同一个组织的不同部门之间，这种能力水平也可能有天壤之别。由于朝着更具支持性的环境迈进对所有人都有好处，因此，提醒高层管理者注意项目优先级与绩效奖励之间的文化冲突，应该成为软件项目经理职责的一部分。
