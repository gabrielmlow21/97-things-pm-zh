Web 指出了方向——至少现在是这样

David Wood

有一个慈善团体的口号是：“我们站在前人的肩膀上。我们为后来的人提供肩膀。”这句话对我们这些软件开发人员很有意义。每当一种新的架构、语言或平台流行起来，我们常常会感叹：“这就是解决所有编程问题的答案。”它也许能解决今天的问题，但明天还会有新的挑战。

目前，我们只知道刚好一种软件架构，能扩展到几十亿用户，同时在个别组件出问题时依然很稳健*：那就是万维网。到目前为止，Web 是人类建造过的最大、使用最多、最稳健的信息检索系统。

为什么 Web 运作得这么好？鼎鼎大名的 Apache** 项目创办人之一罗伊·菲尔丁（Roy Fielding）研究的正是这个问题。菲尔丁分析了早期 Web 的一个理想化版本的架构，从中整理出了架构风格的要素。

结果就是一种新的软件架构风格，拥有我们喜爱的 Web 的那些特点：它们在面对变化和个别组件故障时都很稳健；它们把关注的事情分开，让我们不必再管编程语言这类实现细节；它们用一种共同的“通用语”（让母语不同的人能互相沟通的语言）来交换和语言无关的信息请求；它们非常容易扩展；它们是无状态的。

不是每个网站都用了这些原则，但很多网站都用了，而 Web 整体也用了。不过，这些只是肩膀，新的创新架构会在这之上继续发展。

我们可以从 Web 的成功中学到一些重要的东西。也许最重要的是，摩尔定律***让我们现在在系统设计中可以接受大量的抽象。我们不必再对硬件和软件斤斤计较地追求效率，而是可以考虑让系统极度稳定、极度稳健、极度容易扩展、极度灵活。我们也可以接受现在架构的低效率，因为我们很清楚，它们只是未来创新的基础。

像 Web 这样的分布式系统很难设计。也许是因为我们每个人都是独立的个体。我们把软件系统当成某个人做出来的东西，就像我们每个人都以自己为中心看世界一样。不过，Web 的分布式系统已经为我们指出了方向。分布式系统比较难想清楚，所以也比较难做，但值得花力气去做。

当然，技术会变，想法和方法也会变。菲尔丁描述的那个简单的 Web，不是现在的 Web，也不会是未来的 Web。Web 不一定永远都能指出方向。适应新系统的关键，是现在就把弹性设计进我们的系统里。只有这样，我们才能开始做出有生命力、会呼吸、能适应的软件系统，随时准备好和新的发现结合，为后来的人提供肩膀。

  • 稳健（Robust）——能好好应对各种变化（有时是没办法预测的变化），功能的损坏、改变或损失都降到最低。
  • Apache 项目——一个开源项目，为现代操作系统开发和维护免费的 Web 服务器软件。
  • 摩尔定律（Moore's Law）——描述电脑硬件长期趋势的定律：能便宜地放进集成电路的晶体管数量，以指数速度增长。
