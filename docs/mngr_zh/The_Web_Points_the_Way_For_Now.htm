Web 指出了方向——至少现在是这样

David Wood

有个慈善团体的口号是：“我们站在前人的肩膀上，也为后来者提供肩膀。”这句话对我们这些软件开发人员很有意义。每当一种新的架构、语言或平台声名鹊起，我们往往会感叹：“这就是解决所有编程问题的答案。”它也许能解决今天的问题，可明天又会有新的挑战摆在面前。

目前，我们所知道的软件架构中，恰好只有一种能扩展到几十亿用户，同时在单个组件出故障时依然稳健*：那就是万维网。迄今为止，Web 是人类建造过的规模最大、使用最多、最稳健的信息检索系统。

Web 为什么运作得这么好？大名鼎鼎的 Apache** 项目创始人之一罗伊·菲尔丁（Roy Fielding），研究的正是这个问题。菲尔丁分析了早期 Web 的一个理想化版本的架构，从中提炼出了架构风格的要素。

成果是一种新的软件架构风格，具备我们所钟爱的 Web 的那些特性：面对变化和特定组件的故障都很稳健；关注点相互分离，让我们不必再操心编程语言这类实现细节；用一种共同的“通用语”（即母语不同的人之间用来交流的语言）来交换与语言无关的信息请求；扩展能力极强；无状态。

并不是每个网站都遵循这些指导原则，但很多网站都遵循，Web 整体也遵循。不过，这些只是肩膀而已，新的创新架构会在这之上不断发展。

我们可以从 Web 的成功中学到一些重要的东西。也许最重要的一点是：摩尔定律***让我们如今在系统设计中能够容纳大量的抽象。我们不必再对硬件和软件锱铢必较地追求效率，而可以考虑让系统格外稳定、格外稳健、格外易于扩展、格外灵活。我们也可以接受现有架构的低效，因为我们很清楚，它们只是未来创新的基石。

像 Web 这样的分布式系统很难设计。也许是因为我们每个人都是独立的个体。我们把软件系统当作某个人创造出来的东西，就像我们每个人都以自我为中心看世界一样。不过，Web 的分布式系统已经为我们指明了方向。分布式系统更难构想，因而也更难构建，但值得为之付出努力。

当然，技术会变，想法和方法也会变。菲尔丁所描述的那个简单的 Web，不是如今的 Web，也不会是未来的 Web。Web 未必永远能指明方向。适应新系统的关键，在于现在就把弹性设计进我们的系统。只有这样，我们才能开始构建有生命、会呼吸、能适应的软件系统，随时准备好与新的发现融为一体，为后来者提供肩膀。

  • 稳健（Robust）——能很好地应对各种变化（有时是无法预测的变化），把功能的损坏、改变或丧失降到最低。
  • Apache 项目——一个开源项目，为现代操作系统开发和维护免费的 Web 服务器软件。
  • 摩尔定律（Moore's Law）——描述电脑硬件长期趋势的定律：能以低成本放进集成电路的晶体管数量，呈指数级增长。
